Indonesia in Numbers — a national statistics site: population, economy, health, education, environment and regions for Indonesia, with real figures from the World Bank, BPS — Statistics Indonesia, UNDP and others. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node main.ts
```

Serve `app/` with any static server and open `app/index.html` — for example:

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in a browser. The site is plain static files: no build step, no network requests. Every figure is stored in `app/data.js` and cited on the Sources page.
